# Mizki & Karen

`/mizkiandkaren/` がホーム、`/mizkiandkaren/date_idea` がデート案です。既存の Flask / Render サイトに追加しており、起動コマンドは `gunicorn app:app --threads 4 --timeout 90` です。Googleの応答待ちでほかのページや写真の読み込みが止まらないよう、4スレッドで動かします。RenderをBlueprint管理していない場合は、サービスのSettingsにあるStart Commandもこの値へ変更してください。

タイトルだけで追加でき、メモ・場所・参考URL・予算（円／人）・季節・写真は任意です。春夏秋冬をすべて選ぶと「いつでも」と表示します。写真は案に1枚、達成記録に1枚。各12MB・2,000万画素まで受け付け、長辺1400px以内・350KB以下のWebPへ圧縮し、EXIF情報を落とします。HEICはJPEGに変換してから選んでください。

お気に入り、キーワード、場所、予算の上下限、季節で絞り込み、表示中の「行きたい」からランダムに1件選べます。季節の複数選択は「いずれかに一致」です。季節・予算が未入力の案は、その項目で絞り込むと対象外になります。条件と表示タブはURLに保存します。実施日と感想、思い出の写真は達成時も後からも編集できます。思い出を「行きたい」に戻しても感想・写真を残します。

ホームは非公開の環境変数 `MIZKI_KAREN_ANNIVERSARY_START` を起点に、次の周年までの日・時間・分を表示します。判定はAsia/Tokyoで行い、記念日当日は当年の周年をお祝いします。日時は認証後のHTMLだけに埋め込み、ログイン画面や公開ソースに残しません。保存済みの思い出を最大3件、その下にページへの入口を表示し、今後の追加に使える余白を残しています。

## 別のGoogleアカウントで保存先を作る

このチャットに接続済みのアカウントには何も作成しません。以下は**データを保存したい別のGoogleアカウント**で行ってください。サイトを使う際にGoogleログインは必要ありません。

1. 別のブラウザプロファイル、またはそのアカウントだけでログインしたウィンドウで [Apps Script](https://script.google.com/) を開き、新しいプロジェクトを作成します。右上のアカウントが意図したものか確認してください。
2. `google/Code.gs` の内容をエディタの `コード.gs` へ貼ります。
3. 歯車の「プロジェクトの設定」で「『appsscript.json』マニフェスト ファイルをエディタで表示する」をオンにし、エディタの `appsscript.json` を `google/appsscript.json` の内容で置き換えます。保存すると高度な Drive API v3 が追加されます。標準の Google Cloud プロジェクトを独自設定している場合は、そのプロジェクトでも Drive API を有効にしてください。
4. 関数一覧から `setupJournal` を選んで実行し、**保存用アカウント**で権限を許可します。自分用スクリプトとしてコードを確認してから許可してください。
5. 保存用アカウントのマイドライブに `Mizki & Karen` フォルダ、専用スプレッドシート、非公開の `Photos — private` フォルダが作られます。実行ログにはフォルダとシートのURLだけが出ます。`setupJournal` は再実行しても既存の保存先を保持します。
6. 「デプロイ → 新しいデプロイ → ウェブアプリ」で「次のユーザーとして実行：自分」「アクセスできるユーザー：全員」を選び、デプロイします。`/exec` で終わるURLを控えます。匿名実行を許可できないWorkspaceアカウントでは、この構成は使えません。
7. 「プロジェクトの設定 → スクリプト プロパティ」の `MK_SHARED_SECRET` を確認し、Renderの `MIZKI_KAREN_GAS_SECRET` に設定します。秘密の値をチャットへ送らないでください。

「全員」はWebアプリの呼び出し権限です。シートやフォルダを「リンクを知っている全員」に共有しないでください。APIは時刻・nonce・本文をHMAC-SHA256で検証し、秘密のない呼び出しにはデータを返しません。共有秘密はRenderとApps Scriptだけが持ち、ブラウザへ送りません。写真は認証済みのFlaskルートが中継し、Driveの公開URLを作りません。

Apps ScriptはGoogleの無料枠で動作しますが、実行時間や呼び出し回数、Drive容量の上限があります。有料サービスは追加しません。写真を大量に保存する場合は保存用アカウントの容量を確認してください。

## 合言葉とRenderの設定

ローカルで次を実行します。合言葉をチャットやGitへ書かず、入力を隠してハッシュ化します。

```bash
.venv/bin/python scripts/configure_mizkiandkaren.py
```

生成される `.env.mizkiandkaren` はGit対象外・権限600です。**RenderのEnvironment**に次の5項目を設定します。ローカルファイルをそのままGitへ追加しないでください。

| 環境変数 | 値 |
| --- | --- |
| `MIZKI_KAREN_SECRET_KEY` | 生成ファイルの値 |
| `MIZKI_KAREN_PASSPHRASE_HASH` | 生成ファイルの値。合言葉そのものではありません |
| `MIZKI_KAREN_GAS_URL` | 別アカウントでデプロイした `https://script.google.com/macros/s/.../exec` |
| `MIZKI_KAREN_GAS_SECRET` | Apps Scriptの `MK_SHARED_SECRET` |
| `MIZKI_KAREN_ANNIVERSARY_START` | 生成ファイルの値。交際開始日時のISO 8601表記（日本時間） |

設定後、変更したコードをRenderへデプロイします。合言葉を決めるのは本人だけで構いません。API設定や署名鍵が未設定ならサイトは保存を受け付けず、認証設定が未設定なら準備中の画面になります。本番でブラウザ内保存やRenderの一時ディスクへ自動で切り替えることはありません。

Apps Scriptのコードを変更した後は「デプロイを管理 → 編集 → 新バージョン」で更新してください。コードを保存するだけでは既存の `/exec` には反映されません。

合言葉を変える場合は新しいハッシュを設定します。署名用のsaltにハッシュを含めているため、既存ログインも無効になります。ログインは通常12時間、「この端末で30日間」は30日間。Cookieは本番でSecure・HttpOnly・SameSite=Laxです。ログアウト・編集・削除はCSRF検証を行います。短時間の連続した合言葉入力は制限します（プロセス単位の制限です）。

## ゴミ箱と競合

削除した案は30日間復元できます。30日を過ぎるとサイトから表示・復元できなくなります。`setupJournal` が作る1時間ごとの `purgeExpiredJournal` トリガーで、案の行と2枚の写真を完全削除します。Drive写真はゴミ箱への移動ではなく、高度なDrive APIで完全削除します。Googleのトリガー遅延・権限失効・実行枠超過があると物理削除が遅れるため、Apps Scriptの「実行数」と「トリガー」を確認してください。削除途中の失敗は次回に再試行します。

写真の差し替え後は旧ファイルを削除し、失敗した未参照ファイルは24時間後の定期処理で回収します。30日以内のゴミ箱の写真は回収しません。

同じ案を2台で編集した場合は版番号を確認し、古い画面からの上書きを拒否します。通信が途中で切れた場合、保存済みか判断できないため「最新に更新」で確認してください。複数端末への反映は「最新に更新」または画面に戻ったときの再取得です。常時接続のリアルタイム同期は行いません。

スプレッドシートの列名・版番号・ID・JSON、写真ファイルの名前や保存先は手で変更しないでください。通常の操作はサイトから行います。バックアップする場合はシートと写真フォルダの両方を複製してください。

## ローカル確認

Google接続なしで確認するときだけ `MIZKI_KAREN_LOCAL_DB=/tmp/mizki-karen-preview.sqlite3` を指定できます。認証用の2変数も必要です。SQLiteはローカル検証用で、環境変数 `RENDER` が存在する本番では使いません。HTTPのローカル確認時だけCookieのSecure属性を外します。Google保存先とは同期しません。

```bash
.venv/bin/python -m unittest discover -s tests
node --test tests/google_journal.test.cjs
```

## 公開前の接続確認

別アカウントによるGoogleの承認とデプロイは、この開発環境から代行できません。設定後に本人の2端末で以下を確認してください。

1. 合言葉でログインし、案を1件追加する。もう一方の端末で「最新に更新」し、表示を確認する。
2. 写真を案と達成記録に1枚ずつ保存し、ログアウト中は写真URLが401になることを確認する。
3. ゴミ箱へ移し、もう一方の端末から復元する。
4. Apps Scriptの時間トリガーが1時間ごとに登録されていることを確認する。

Googleへの実接続は、この確認が完了するまでは未検証です。
