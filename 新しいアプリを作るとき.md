# 新しいアプリを追加する

アプリのコード・HTML・CSS・データを `apps/<アプリ名>/` にまとめます。既存の `apps/rocket/` などが実例です。以下は `/weather` で表示する HTML ページの最小例です。

## 1. アプリのフォルダを作る

```text
apps/weather/
├── __init__.py
├── routes.py
├── templates/
│   └── weather.html
└── static/             # CSS や画像が必要な場合だけ
```

`apps/weather/routes.py`:

```python
from flask import Blueprint, render_template

weather_bp = Blueprint(
    "weather", __name__, template_folder="templates", static_folder="static"
)

@weather_bp.route("/weather")
def index():
    return render_template("weather.html")
```

HTML だけのアプリも同じ形で追加できます。CSS は `apps/weather/static/style.css` に置き、HTML から `{{ url_for('weather.static', filename='style.css') }}` で参照します。データファイルは作業ディレクトリに依存しないよう、`Path(__file__).with_name('data.json')` のようにアプリのフォルダから参照します。

## 2. ルートを登録する

`app.py` に `from apps.weather.routes import weather_bp` を追加し、ほかの Blueprint と同様に `app.register_blueprint(weather_bp)` を追加します。Render の起動コマンドは変更不要です。

## 3. トップページのカードを設定する

`portfolio/projects.py` の `PROJECTS` に次の項目を追加します。

```python
{
    "id": "weather",
    "visible": True,  # False ならトップページから隠す
    "cards": [{
        "endpoint": "weather.index",
        "title": "天気アプリ",
        "description": "天気を表示",
        "image": "画像の URL",
    }],
},
```

`endpoint` は `Blueprint名.関数名` です。`visible=False` でも `/weather` は直接開けます。`cards` に複数入れると、1つのアプリの複数ページをまとめて表示・非表示にできます。

最後に `.venv/bin/python -m unittest discover -s tests` を実行し、新しいページもブラウザで確認してください。
